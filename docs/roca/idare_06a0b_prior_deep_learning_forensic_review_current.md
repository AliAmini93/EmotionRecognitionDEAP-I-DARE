## Interpretation

The prior deep-learning artifacts are useful, but the current evidence suggests they mostly document smoke/stabilization, binary-label, oracle, or architecture-ablation paths. The current ROCA target has shifted to residual/deviation predictability under locked subject-held-out gates. Therefore the next model should not be a broad architecture search. It should start with a minimal arousal high-disagreement EEG representation prototype, because 05ajb is the only place where fixed physiology produced confirmed residual signal.
