- `kshot_subject_mean_only` is not a physiology model and not zero-shot LOSO. It tests how much labelled subject calibration alone can explain the high-disagreement residuals.

- If fixed EEG-bandpower plus k-shot is worse than subject-mean-only, physiology is not adding useful information after calibration.
