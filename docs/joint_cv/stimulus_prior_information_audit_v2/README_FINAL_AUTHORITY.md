# Stimulus-Prior Information Audit v2 — Shared Authority

Status: **FROZEN SHARED EVIDENCE AUTHORITY**

This package is the independently revalidated archival successor for the
stimulus-associated-prior evidence used to motivate strict joint
subject-stimulus evaluation.

Primary datasets: DEAP and I-DARE.
External validation: DEJA-VU.

This package is intended to be referenced by both Paper 1 and Paper 2.

The bounded result is that subject-only evaluation can leave canonical
stimulus novelty uncontrolled, and that substantial source-derived
stimulus-associated label information exists for DEAP and I-DARE.

This package does not claim that subject-only CV is intrinsically invalid,
that sample/data leakage occurs, or that a physiological model necessarily
exploits stimulus identity.
