## Scientific Question

Do the current I-DARE EEG/EMG features contain measurable cross-subject label signal at all?

This branch is diagnostic only. It does not train classifiers and does not attempt to improve the model.

## Registered Diagnostics

### D1: Cross-subject feature effect size

Estimate label-related feature signal using Cohen's d for valence and arousal.

### D2: Within-subject vs cross-subject discriminability gap

Compare subject-centered/cross-subject signal against within-subject signal.

### D3: Subject-vs-label clustering dominance

Estimate whether feature variance is dominated more by subject identity than by emotion label.

### D4: Top-feature stability

Check whether top discriminative features are stable across subject folds.

## Decision Logic

- If cross-subject signal exists but classifiers are weak, model/formulation/preprocessing is the likely bottleneck.
- If within-subject signal exists but cross-subject signal collapses, subject normalization/domain generalization becomes priority.
- If no measurable signal exists in current features, representation is the likely bottleneck.
- If subject identity dominates label signal, subject normalization or subject-invariant objectives should be prioritized before bigger model runs.
