## Matrix

3. P0 as comparator only.
4. P4 as fallback.

## Future Lock Requirements

A future target-policy lock must state:

- selected scientific target,
- selected label policy,
- selected evaluation protocol,
- comparator baseline,
- whether subject-relative task is in scope,
- what result would count as success,
- what remains frozen or forbidden.
