## Design Being Validated

- Main subject set: 63 common EEG+EMG subjects.
- Task labels: `label = 1 if score > 5 else 0`; `score == 5` discarded per task.
- Trial unit: one I-DARE emotional `STIM_*` event.
- Slicing policy: start at `event_begin`, extract exactly 5.0 seconds.
- EEG source: 512Hz, first 32 channels, downsampled by 4 to 128Hz.
- EEG tensor shape: `[32, 640]`.
- EMG source: 2000Hz, two channels.
- EMG tensor shape: `[2, 10000]`.
