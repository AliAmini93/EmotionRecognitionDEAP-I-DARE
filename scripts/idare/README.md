# I-DARE Script Archive

This directory contains committed, reusable I-DARE workflow scripts.

## Policy

- New I-DARE reports should be generated by scripts committed under this directory, not only by ad-hoc files under `~/Downloads`.
- Each script should reference the objective document it implements.
- Each script should validate inputs and outputs.
- Scripts must not run blocked work unless a reviewed objective explicitly authorizes it.
- Historical scripts may be backfilled only when reconstructable from logs; reconstructed files must be labeled as reconstructed, not original.

## Layout

- `scripts/idare/analysis/`: read-only diagnostic/report scripts.
- `scripts/idare/archive_or_reconstructed/`: optional backfilled historical scripts, only when provenance can be represented honestly.

## Active pause point

The current scientific analysis is paused at:

`docs/idare_label_semantics_minimal_redesigned_task_failure_or_confirmation_analysis_objective.md`

The next analysis must be run from:

`scripts/idare/analysis/run_idare_label_semantics_minimal_redesigned_task_failure_or_confirmation_analysis.py`

after this reproducibility layer has been reviewed.
